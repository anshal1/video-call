# Huddle — Client

Next.js frontend for Huddle, a peer-to-peer group video calling app.

See the [root README](../README.md) for full documentation, architecture, and setup instructions.

## Quick start

```bash
npm install
echo "NEXT_PUBLIC_SIGNAL_SERVER=http://localhost:5000" > .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The signaling server in `../server` must be running.
